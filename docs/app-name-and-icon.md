# App 名字和图标

2026-10-26 定下：名字叫 **拍照算番**，图标用 **C1 粗宋「和」**。

## 图标

<img src="assets/app-icon/C1.svg" width="160" alt="拍照算番 App 图标：纸白底上一个墨色粗宋「和」，右下一个朱红小方块">

- 纸白底（`#F7F6F2`），墨色粗宋「和」（`#16150F`），右下一个朱红小方块（`#C23B22`）像落款。和 App 的「墨与朱」视觉同一套颜色。
- 「和」是 Noto Serif SC Black 的字形，已经转成路径，不依赖任何字体。
- iOS 18 的深色和着色外观各有一版：深色是纸白字加朱红方块、透明底；着色是白字加灰方块、透明底，由系统上色。
- 源文件在 [assets/app-icon/](assets/app-icon/)，App 里用的 1024 PNG 在 `app/MajiangApp/Resources/Assets.xcassets/AppIcon.appiconset/`。浅色那张没有透明通道，App Store 要求如此。
- 当时一共画了 40 个方案（朱印、一张牌、一个字、取景框、牌桌记账、极简几何六个方向），C1 是 Yang 选的。

## 名字

主屏上显示「拍照算番」。App Store 全名 1.0 只填了「拍照算番」，1.0.1 起改成「拍照算番 - 国标麻将计分器」（名字最多 30 个字），让搜「国标麻将」「麻将计分」的人都能找到；副标题和关键词见 [app-store.md](app-store.md)。

为什么不叫原来的「国标记分」：

- 「国标」单独出现不说麻将，容易被当成国家标准，App Store 里就有查标准的「国标通」。
- 「记分」太普通，计分类 App 很多，也没说出拍照认牌这个卖点。

2026-10-26 在 App Store 上查过的同类 App（都没有叫「拍照算番」的）：

| App | 做什么 |
|---|---|
| 麻将AI小番 - 胡牌分析 | 支持国标等多种规则，能拍照识别手牌，最接近的竞品 |
| 国标麻将-超级工具 | 国标算番和出牌提示，没有拍照 |
| 麻薯计番器 | 离线记番记分 |
| 血战麻将算番器 | 血战规则，不是国标 |
| 麻将计分器 - Mahjong Scorer、简单麻将计算机 | 只记分 |

名字最终能不能用，要在 App Store Connect 里新建 App 时填进去才知道。别人已经占了的名字会直接提示不能用。

## 在 App Store Connect 里占名字

1. 打开 [App Store Connect](https://appstoreconnect.apple.com) → 我的 App → 左上角「+」→ 新建 App。
2. 平台选 iOS；名称填「拍照算番 - 国标麻将计分记账」（被占了就先只填「拍照算番」）；主要语言选简体中文；套装 ID 选 `com.yangwy30.majiang`；SKU 随便填一个，比如 `majiang`。
3. 点创建，名字就占住了。占住之后不用马上提交审核，但苹果规定了上传构建版本的期限，太久不传名字可能被收回，具体以 App Store Connect 的提示为准。
